Course Introduction

Course Overview

This course is an introduction to algorithms and design patterns. Students will learn to develop efficient and elegant software algorithms for complex problems faced by video game programmers. Students will also explore several advanced object-oriented data types and algorithms available in a modern object-oriented programming language and game engine.

Course format

This course consists of learning modules comprised of module lectures and projects.

Each module is composed of the following components:

In-Person and Online Lectures

Each week your instructor will delivery one in-person lecture, with your second weekly lecture delivered over MS Teams during your scheduled class time. You are expected to attend all these lectures in real time so that you ask questions and participate in the associated individual or group activities. These lectures will also be recorded so that you can review the material afterwards.

Projects

You will also be assigned a number of large projects throughout the term. These projects are meant to be purely individual work and will incorporate material from all of the preceding modules.
